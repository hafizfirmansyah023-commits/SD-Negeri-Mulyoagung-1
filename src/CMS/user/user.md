Tambahkan fitur **ikon mata (show/hide password)** pada bagian **Card Edit Profile**, sehingga pengguna dapat menampilkan atau menyembunyikan password saat mengisi atau mengubah password.

Selain itu, terapkan ketentuan keamanan password dengan **panjang minimal 6 karakter** untuk seluruh password pengguna. Sistem harus melakukan validasi dan menampilkan pesan peringatan apabila password yang dimasukkan kurang dari 6 karakter.
